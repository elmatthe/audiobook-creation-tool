| **First-run setup, launch and release** | `bootstrap.py` (setup, repair, launch), `bootstrap_host_macos.sh` (macOS stage 0: the app's own Python, proved or downloaded with consent and verified, in bash 3.2; the mirror of `bootstrap_host.ps1`), `child_ownership.py`, `child_entry.py`, `child_guardian.py` and `child_launch.py` (macOS: setup's children are owned -- a lifeline ends ACT's Python children and the guardian ends external programs when their owner is gone, however it went; standard library only), `engine_lease.py` (the locks a held voice engine's users hold, taken together before the environment is changed), `uv_runner.py` (v0.8.2 Phase 4: the one wrapper every uv command of the app runs through -- the pinned uv and managed CPython 3.12.15, the base project's `uv sync --locked` per user/dev profile, offline first, the app-folder cache and a contained, scrubbed environment; standard library only), `app_python.py` (v0.8.2 Phase 4: the one resolver of the copy's base interpreter -- uv's managed CPython, or the legacy `files/runtime-data/python` while `.venv` still runs on it; standard library only), `base_packages.py` (retired from the app in v0.8.2 Phase 4, which syncs `pyproject.toml` and `uv.lock` with uv instead; kept only for the developer lock generator of the v0.8.1 requirement locks until that seam is removed; standard library only), `nltk_store.py` (the Edge voices' English sentence data, pinned and verified in `files/runtime-data/nltk_data`, fetched only with consent; standard library only), `long_paths.py` (Windows long-path support against the depth of the app's folder: reads the setting, gives the first-run window its two ways forward, switches the setting on only with consent through Windows' own prompt and `reg.exe`, and proves in a fresh process that long paths work; standard library only), `close_terminal.py` (macOS), `espeak_data.py`, `logging_setup.py`, `version.py`, `release.py` (developer packaging, not part of the running app) |
